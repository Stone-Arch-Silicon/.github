## Start building

New to the flow? Follow the [ASIC 101 course map](https://github.com/Stone-Arch-Silicon/ASIC_101#readme): setup → RTL → simulation → FPGA → synthesis and physical design → verification and handoff. Keep a record of the commands, tool versions, reports, and results you can reproduce.

To contribute, choose the repository that owns the work, read its README, and open an issue describing the change or a focused pull request with validation steps. Documentation fixes, reproducible examples, test cases, and clear engineering explanations all help.

## Connected community

Explore [ASIC Network](https://github.com/ASIC-Network) for the broader community, analog and digital learning material, and shared silicon initiatives. Individual repository histories credit the contributors behind each project.
